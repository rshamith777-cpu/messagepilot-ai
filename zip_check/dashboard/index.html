🏗️ End-to-End Multimodal System Architecture
1

Multimodal Pre-Processing Subsystem

Executes EasyOCR/Pytesseract for images (detecting QR code/payment keywords) and Faster-Whisper for voice notes, prepending clean text to incoming payload.

2

Context Builder & Feature Extraction

Extracts Do-Not-Disturb windows, business opt-out status, direct mentions, domain mismatches, and suspicious URL patterns.

3

Okapi BM25 & Fuzzy Evidence Retriever

Filters candidate history by entity matching, computes BM25 relevance scores, token ratio similarity, recency decay ($t_{1/2}=90\text{d}$), and user reaction signals.

4

Additive Hybrid Scorecard Engine

Computes explicit, explainable score vectors ($S_{notify}, S_{digest}, S_{mute}$). High confidence ($>0.90$) bypasses external LLM API calls instantly.

5

Confidence Calibration & Decision Graph Logger

Calculates score-gap confidence clamped to $[0.35, 0.98]$, outputs row to `dataset/output.csv`, and logs structured trace to `decision_traces.jsonl`.

ℹ️ System Summary & Key Technical Features

MessagePilot AI is a production-grade notification routing engine built for WhatsApp. It solves notification overload by combining deterministic scorecards with multimodal AI and evidence retrieval.

⚡ Sub-Millisecond Speed

Additive scorecard engine routes high-confidence messages in sub-milliseconds without LLM latency.

🛡️ Zero-Trust Security

Detects domain mismatches, credential phishing, Hinglish scam patterns, and prompt injection attempts.
